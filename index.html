02 / Built for agent workflowsAIエージェントと計算する

Many agents.
One shared resource budget.エージェントは複数。
リソース管理はひとつに。

Let agents submit work through the local API. On a workstation, the shared helper queue schedules calculations within the CPU and memory budgets you set, helping prevent a flood of submissions from overloading the machine.複数のAIエージェントからローカルAPIへジョブを投入。ワークステーションでは、共通のヘルパーキューが設定したCPU・メモリ予算に応じて実行を調整し、集中投入による過負荷を抑えます。

8 cores + 32 GB budget予算が 8 コア・32 GB ならTwo jobs requesting 4 cores and 16 GB each run together. Additional jobs wait for capacity.各 4 コア・16 GB のジョブは同時に2件まで。残りはリソースが空くまで待機します。
Explore the APIAPIドキュメントを読む →
Python / agent workflow
from job_manager.api_client import JobManagerClient

client = JobManagerClient()
job = client.submit(
    host="workstation",
    files=["molecule.inp"],
    command="/opt/orca/orca {input} > {stem}.out",
    cpus_per_task=4,
    memory="16GB",
)

final = client.wait(job["id"])
if final["state"] != "DONE":
    raise RuntimeError(final["state"])
results = client.download(job["id"], wait=True)
Local HTTP API · Token authentication · Python standard library clientローカル HTTP API · トークン認証 · Python標準ライブラリのみのクライアント

Use the same host profile and helper queue, with accurate resource requests. Budgets schedule declared requests; they do not enforce process limits or account for unrelated applications. Force run bypasses budgets. Cluster destinations use their own scheduler. The API is opt-in, loopback-only, and requires Job Manager to be running.同じホスト設定・ヘルパーキューを使用し、実際の使用量に合ったリソースを申告してください。予算は申告量に基づく実行調整であり、プロセスの使用量を強制制限したり、他のアプリの負荷を計上するものではありません。Force runは予算を迂回します。クラスターでは既存のスケジューラーが管理します。APIは明示的に有効化した場合のみ同じPC内で利用でき、Job Managerの起動が必要です。

05 / Ready for your next calculation次の計算をはじめよう

Give your jobs
a place to land.計算ジョブに、
いつもの居場所を。

Free and open source. Start with the MoleditPy plugin, or run the desktop app independently.無料・オープンソース。MoleditPyのプラグインから、または単独のデスクトップアプリとして利用できます。

Open Plugin ExplorerPlugin Explorer を開く ↗Releasesリリース →

  1. Install Job ManagerJob Manager をインストール

    In MoleditPy 5.x, open the Plugin Installer and install Job Manager from the official plugin collection.MoleditPy 5.xのPlugin Installerを開き、公式プラグイン一覧からJob Managerをインストールします。

  2. Connect a host計算先を設定

    Open Extensions → Job Manager → Job Monitor → Hosts. Choose a backend and scheduler, configure resources, and test the connection.Extensions → Job Manager → Job Monitor → Hostsから、バックエンド・スケジューラー・リソースを設定し、接続をテストします。

  3. Submit your first calculation最初のジョブを投入

    Choose New Job, add your inputs and check the script preview. For automation, enable Local API and follow the API guide.New Jobで入力ファイルを追加し、スクリプトを確認して投入。自動化にはLocal APIを有効化し、APIガイドを参照してください。

Already have the package on your Python path?パッケージをPythonから参照できる環境なら：python -m job_managerStandalone: Python 3.10+ and PySide6-Essentials. See the README for backend requirements.単体利用にはPython 3.10+とPySide6-Essentialsが必要です。バックエンド別の要件はREADMEを参照してください。
